Projects based on the metatensor ecosystem

This is an (incomplete) list of libraries and software tools that use the metatensor libraries and tools.

Libraries

  • sphericart

    A multi-language library for the efficient calculation of real spherical harmonics and their derivatives in Cartesian coordinates, including fast CUDA kernels. See the documentation for an example of the metatensor interface.

  • torch-spex

    A library to evaluate a spherical expansion of the neighbor density - the basic ingredient of atom-density representations.

Simulation tools

  • chemiscope

    An interactive structure-property explorer for atomistic simulation data. chemiscope.explore can use metatomic models to generate features to describe structures and atomic environments.
